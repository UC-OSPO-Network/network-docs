# Biodiversity Analysis Toolkit

## About

Analysis tools for biodiversity research data. This demo version generates a sample dataset and prints its mean and standard deviation. It's a teaching repository for the "Making Research Software Citable & Discoverable" lesson.

## Features

- Summary statistics (mean and standard deviation) in one command
- Runs anywhere Python and NumPy run
- Citable, with a license, a CITATION.cff file, and a DOI

## Getting Started

You need Python 3.9 or later.

```bash
git clone https://github.com/YOUR-USERNAME/software-demo.git
cd software-demo
pip install -r requirements.txt
```

## Usage

```bash
python src/analysis.py
```

This prints the mean and standard deviation of the sample data.
