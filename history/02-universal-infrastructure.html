Universal Infrastructure

1986 - 2000 · UCLA, UC Berkeley

Some software is so fundamental it disappears into the background. You never think about it until it breaks. The two projects in this chapter run on every networked device on the planet. Neither was built to become infrastructure. Both were built to solve a specific, annoying problem.

The tz Database: Every Clock on Earth

The project: tz database (IANA Time Zone Database) Campus: UCLA (Paul Eggert: contributor since 1991, maintainer since 2005, IESG-designated coordinator since 2012) Origin: 1986, Arthur David Olson (NIH) Key figures: Paul Eggert (UCLA), Arthur David Olson

Section in preparation.

What it became

Linux, macOS, iOS, and Android all ship with the tz database. Paul Eggert first worked on it in 1991, when Olson maintained it at NIH (UC Tech News, 2022). He has been its maintainer since 2005 (Eggert, 2026). Every programming language that handles dates and times depends on it. When a country changes its clocks (and they do, constantly - political decisions, wars, referenda), Paul Eggert updates the database and the world’s computers follow.

The lawsuit that almost broke time

In September 2011, Astrolabe Inc. sued Arthur David Olson and Paul Eggert, claiming copyright over historical time zone data (Electronic Frontier Foundation, 2012a). The Electronic Frontier Foundation, with co-counsel at Fish & Richardson, defended them (Electronic Frontier Foundation, 2012b). The database went offline on 7 October 2011. ICANN brought it back online at IANA on 14 October 2011, and Robert Elz served as interim coordinator. Astrolabe dropped the suit on 22 February 2012 (IETF, 2012). The IESG approved Eggert as the Time Zone Coordinator on 13 April 2012 (IESG Secretary, 2012). Olson’s announced retirement had led the IETF to ask ICANN to take over the database (ICANN, 2011). The episode showed how much depended on a very small group of maintainers.

Apache HTTP Server: “A Patchy” Web Server

The project: Apache HTTP Server Campus connection: UC Berkeley (Brian Behlendorf, undergraduate) Period: 1995 - Key figures: Brian Behlendorf (UCB undergrad), Cliff Skolnick, and eight founding contributors

Section in preparation.

What it became

Apache HTTP Server was the most widely used web server for many years. In Netcraft’s December 2015 survey it still ran 50.14% of active sites (Netcraft, 2016). The Apache Software Foundation, which grew from the original group, reported 308 projects in November 2026 (The Apache Software Foundation, 2026), including Apache Spark, which appears later in this history.

The Berkeley connection

Behlendorf’s Berkeley connection is indirect: he was a student there, not running a lab project. But his story illustrates something important about how infrastructure gets built. He was not a professor with a grant. He was an undergrad with a server and a problem. The permissive culture Berkeley embodied - share the code, see what happens - was something he had absorbed.
